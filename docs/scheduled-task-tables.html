定时任务管理

页面：pages/scheduled_task.html · 接口前缀：/api/v1/scheduledTask · 需求：[29]

1. 功能说明

  • 在「RRS配置」下可视化管理平台定时任务：展示、启停、修改 cron、手动执行、查看历史。
  • 配置持久化在 sys_scheduled_task，修改后即时重挂载，不再依赖 yml 写死。
  • 关闭定时调度后仍可「立即执行」。

2. 核心表

表名说明
sys_scheduled_task任务配置：cron、启停、扩展参数、最近执行摘要
sys_scheduled_task_evt配置变更审计
sys_scheduled_task_run_log执行历史（手动/定时；detail_log 过程日志）

3. 接口

路径说明
queryTaskList任务清单（库表）
queryTask单任务详情
addTask新增任务配置
editTask修改任务配置并重挂载
deleteTask逻辑删除并取消调度
executeTask立即执行（须有业务实现）
queryRunLogPage执行历史分页

4. 内置任务

编码名称默认 Cron扩展参数（仅 JSON）
auto_out_expired到期出池0 0 2 * * ?{"poolIds":[15]}
company_new_bond_auto_in主体下新债自动入池0 0 3 * * ?{"poolIds":[15]} 可多个；不同池用 mappings

5. 初始化

脚本工具执行 rrs_scheduled_task_schema.sql 与 demo；应用启动时会按代码实现自动补全缺失任务配置。
