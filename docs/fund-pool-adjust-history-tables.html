业务流程总览

以基金调库申请日志为主线查询全状态历史，支持条件筛选、分页、关联详情与 Excel 导出。

1. 加载历史选项加载基金投资池树和日志中的基金品种。
2. 设置历史条件按基金、投资池、提交时间、调整类型和审核状态筛选。
3. 分页查询流水读取未删除的基金调库日志，包含全部审核状态。
4. 查看关联详情点击基金名称或代码查看该次申请、步骤和附件。
5. 导出历史结果导出当前筛选匹配的全部日志，不含页面序号。

历史分页查询

历史来源是申请日志，不是当前池状态；未通过的申请也保留在历史中。

POST /api/v1/fundPoolAdjustHistory/queryFundPoolAdjustHistoryPage · queryFundTypeList · exportFundPoolAdjustHistoryExcel

主查询

  • 主表 ip_adjust_log_fund al，固定 al.is_deleted=0，不限定 audit_status=20。
  • 左连接有效投资池，内连接有效基金品种字典；基金名称取日志快照 COALESCE(al.fund_name, al.fund_short_name)。
  • 按 submit_time DESC, adjust_batch_no DESC, id DESC 排序；品种选项从历史日志中去重。
  • 列表展示分页连续序号、调整人、提交时间、基金名称、代码、品种、调整类型、方向、投资池和审核状态。

筛选与派生

  • poolIds 多选；fundCode / fundName 分别模糊匹配代码、全称或简称；securityType 精确匹配。
  • adjustTimeStart / adjustTimeEnd 控制提交时间范围，结束日期拼接 23:59:59，包含当日数据。
  • adjusterName 模糊查询；adjustMode / auditStatus 按选中枚举筛选。
  • 池树调用 POST /api/v1/common/queryPoolTreeList，限定基金大类；服务补齐池层级路径。

历史详情与导出

详情关联本次历史记录，导出保持同一筛选口径。

POST /api/v1/fundPoolAdjustHistory/exportFundPoolAdjustHistoryExcel

详情入口

  • 本页不设置独立操作列；点击名称或代码打开基金调库详情。
  • 传递基金代码、调整日志 ID、批次号及目标池 ID，定位对应批次与池。
  • 终态日志保留提交时的基金名称和代码；临时代码转正不覆盖已结束历史。

导出格式

  • 输出所有匹配日志；不导出页面序号，其余业务字段与列表一致。
  • 使用 .xlsx，沿用债券历史模板、楷体、20 磅行高与15字符列宽。
  • 数据区保留网格显示，不额外设置底边框；枚举导出为对应业务中文。

关键规则与当前实现说明

  • 历史日志与当前有效池状态是不同口径；当前在池记录见 基金池查询。
  • 审核状态包含 -1 无效、00 流程中、11 驳回待修改、20 审批通过、21 审批驳回、32 O32 自动审批预留、99 发起人已撤回。
  • 调入、调出和调整类型使用日志值；字典名称和状态颜色由前端统一转换，空值留空。
  • 本页只读；审批、重提或终止在基金调库审核页办理。
只有最终审批通过才改变基金池状态；历史查询保留各状态下的申请轨迹。
