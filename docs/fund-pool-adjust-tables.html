业务流程总览

基金独立调库链路：查询基金、查看当前池、选择调入调出池、校验规则、选择一般流程并提交基金申请。

1. 查询基金筛选基金代码、简称、品种和管理人。
2. 查看与选池读取只读基金资料及当前池，选择调入、调出投资池。
3. 校验调整项填写必填基金资料，校验手工项并扩展联动、互斥项。
4. 确认流程与材料选择一般流程，按池规则提供报告和其他材料。
5. 提交与推进生成 FUND 批次及审批步骤，最终通过后更新基金池状态。

主页面基金查询逻辑

基金资料直接读取主档；申请不建立单独基金信息快照表。

POST /api/v1/fundPoolAdjust/queryFundPage · queryFundTypeList · queryFundDetail

查询主线

  • 分页查询有效基金主档并关联基金品种字典，排除已终止或退市基金。
  • 列表包含代码、简称、全称、品种、最新净值、成立日期、基金经理、管理人、规模和数据日期。
  • 点击基金进入只读详情，展示托管人、累计净值、投资风格、价格和发行规模等资料，并强调最新净值。

筛选条件与详情用途

  • fundCode 基金代码、fundShortName 基金简称、securityType 品种、fundAdministrator 管理人。
  • pageIndex / pageSize 控制分页；品种下拉限定基金大类。
  • 详情同时展示当前调整人和更新时间；不采集发行主体、担保人、主体所在池或财务报表。

当前所在池与可调池查询逻辑

以当前已生效池状态作为选池和校验依据，分别展示调入与调出方向。

POST /api/v1/fundPoolAdjust/queryFundPoolStatus · queryAdjustPoolList

基金当前所在池

  • 读取 ip_pool_status_fund，固定 audit_status=20、is_deleted=0。
  • 由投资池服务回填完整池路径，展示基金当前有效成员关系。
  • 未结束申请只用于在途冲突校验，不作为已在池状态展示。

可调入 / 可调出池

  • 读取投资池、权限、基金当前成员关系和池关联配置，按基金业务范围生成两侧候选。
  • 调入/调出方向分别校验池配置与当前成员关系；禁用、锁定和权限限制由后端再次校验。
  • 前端选池用于生成手工调整项，后端校验再扩展联动与互斥项，返回每项结果和可选一般流程。

调入 / 调出校验逻辑

规则在预校验及提交复核时执行，关联项与主项一起构成完整申请。

POST /api/v1/fundPoolAdjust/checkAdjust

基金与投资池规则

  • 检查基金有效性、品种、市场、证券状态，池启用与锁池、用户权限、调入调出资格和当前池状态。
  • 校验容量、同基金同池在途申请、近期重复、来源池、调入/调出/弹性限制、联动互斥、冻结期和开放日。
  • 基金不适用债券到期、主体评级矩阵、担保人、主体禁投和财务校验；不启用 fund_rate_limit 评分区间。
  • 报告要求按目标池和方向区分“不限 / 任一 / 内部”等配置；不能仅凭前端已通过结果跳过服务复核。

必填调库资料

  • fundScore 必填数值，0有效；DECIMAL(10,4) 最多6位整数和4位小数。
  • fundInvestmentType 必填：stock / equity_hybrid / money_market / bond_hybrid / other。
  • needRiskLeaderApproval 必填，取 0 / 1；三项仅采集，不影响准入规则或审批节点。
  • 调整原因、调整建议可选；三项必填资料复制到手工及所有关联日志。

提交申请与审批推进逻辑

提交建立基金专属日志和步骤，审批完成后才改变基金当前池状态。

POST /api/v1/fundPoolAdjust/addAdjustLog · addAdjustLogWithFiles · submitAdjustAudit

提交与一般流程

  • 服务重读权威基金名称、简称和品种，复核完整手工及关联项，不信任客户端传入的主档快照。
  • 仅使用投资池配置的已发布一般 in_flow_id / out_flow_id；不展示快速或批量流程。
  • 生成 FUND 批次，手工项及联动、互斥项共享批次及流程快照，写入 ip_adjust_log_fund / ip_adjust_step_fund。
  • 初始审核状态00；审批按快照推进。最终20新增调入状态或软删除调出状态，11/21/99不落池。

附件、报告与 PDF

  • 附件关联 sys_attachment.table_name=ip_adjust_log_fund，按每个目标池绑定报告与其他材料。
  • 报告分类 fund_report_hand / fund_report_in / fund_report_out；其他材料 fund_material_hand / fund_material_in / fund_material_out。
  • 内部和外部报告页签默认基金代码查询，展示全部报告类型；按池限制校验来源类型。
  • PDF 复用通用导出，排除操作控件、基金调库输入字段、调整原因和建议。

涉及表、用途与触发场景

按本模块实际执行阶段标注读写；表组内具体表的作用见用途与触发场景。

表名用途读写触发场景
rrs_fundinfo基金主档、名称、类型与只读基础信息。查询查询候选基金、打开详情、校验和提交时重新读取权威主档。
dict_security_type基金品种字典；限定 category_type=fund 且未删除。查询品种下拉、基金大类校验与品种名称展示。
ip_investment_pool投资池层级、基金范围、容量、锁池、报告限制及一般流程配置。查询加载池树或目标池、回填完整池路径、执行调入调出校验。
ip_pool_permission用户及角色的可调库、可 Excel 导入权限。查询查询可操作池和提交申请时校验池权限；导入另校验 excel_importable。
ip_pool_relation池联动、互斥关系。查询校验时扩展关联调整项，提交时核验完整调整组。
ip_pool_open_day投资池开放日区间。查询基金调入受开放日限制的投资池时校验。
ip_pool_status_fund基金当前有效在池状态及入池时间。查询新增更新申请阶段读取 audit_status=20、is_deleted=0；最终审批通过后新增调入状态或软删除调出状态。
ip_adjust_log_fund手工及关联调整日志、基金调库字段、批次与一般流程信息。查询新增更新提交生成 FUND 批次、状态 00；审批更新状态；驳回修改阶段更新调整原因和建议。
ip_adjust_step_fund基金批次节点、处理人及处理记录。查询新增更新提交建立开始、发起和待处理步骤；审批推进、会签、驳回与重提时读写。
wf_flow_definition / wf_flow_version / wf_flow_node / wf_flow_edge一般流程定义、已发布版本、节点与连线。查询选择一般流程并生成申请流程快照；本模块不提供快速或批量流程选项。
wf_node_approval_config / wf_node_approval_handler一般审批节点策略与配置处理人。查询读取发布版本的审批配置和处理人，识别人工、自动及 O32 策略，生成或推进步骤。
ais_inv_analysis.t_sys_user / t_sys_role / t_sys_user_roleAIS 用户、角色与用户角色关系。查询解析池权限和节点处理人。表名省略同组后两表的库名前缀。
sys_attachment基金报告和其他材料的附件关联。查询新增上传或复制材料并绑定 ip_adjust_log_fund；审核详情查询、下载附件。
rrs_report_in / rrs_report_out内部、外部报告资料。查询申请时选择报告来源并按投资池报告限制校验。
rrs_temp_fund_code基金临时代码登记。查询按 temporary 状态识别临时基金，将其 O32 节点转人工待处理。

关键规则与当前实现说明

  • 基金使用独立日志、步骤和池状态表；不存在额外基金信息快照表。日志记录一般流程信息，步骤关联发布版本节点。
  • 最终审批落池前锁定基金主档，按最新基金、目标池和关系重新校验整批调整项；在途冲突检查排除当前审批批次。
  • 有效临时基金主档状态 L 可参加申请；临时代码 O32 节点转人工 pending，正式代码 O32 仍按原配置执行。
  • 转正式仅替换00/11在途基金日志代码及相关正式资料，保留原批次、步骤和附件；终态、已提交 Excel 历史及净值历史不迁移。
  • 审批权限、会签和重提说明见 基金池调库审核与详情；全状态申请见 基金池调整历史。
提交成功表示申请已建立；基金是否已入池或出池，以最终审批状态20及有效池状态为准。
