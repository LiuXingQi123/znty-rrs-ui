业务流程总览

前端 pages/stock_pool_excel_import.html：双参数面板与“导入明细 / 调库校验”双页签；目标池由 Excel 解析。

1. 导入参数选择调入/调出、清空及联动互斥，填写整批原因意见。
2. 下载并上传按四列模板上传 xls/xlsx，保存股票导入暂存批次。
3. 导入明细查看真实行号、名称代码、父子池与筛选分页。
4. 调库校验复用股票规则，展开清空与关系项并显示失败原因。
5. 选流程提交选择一般人工流程，整批复核写申请，审批通过后生效。

导入参数与上传

上传后方向、清空和关系选项固定；原因意见可在提交前继续修改。

POST /api/v1/commonFile/downloadTemplate POST /api/v1/stockPoolExcelImport/uploadExcel

导入类型与选项

  • 股票独立入口，方向 in/out；默认 in、clearTarget=false、allowLinkMutex=true，不需要证券/主体类型切换。
  • 页面不手选目标池；以直接父池名称 + 子池名称解析启用、支持股票的叶子池，多匹配明确失败。
  • 首先清空目标池仅适用于调入；联动互斥开关决定提交主项及通过关系项，硬性来源/限制规则仍保留。
  • 上传后固定选项锁定，更改须清空后重新上传；原因与意见整批共享、选填，各最多 1000 字，保存到主表 TEXT 槽 fld011/012。

模板与上传

  • 固定四列：父池名称、子池名称、股票名称、股票代码；代码使用文本格式保留前导零及市场后缀，名称以真实主档为准，评级读取已有记录。
  • 下载 /api/v1/commonFile/downloadTemplate，templateCode=stock_pool_import；楷体 11 磅、浅蓝加粗表头、行高 20 磅、列宽 18，第二表附填写说明。
  • 内置 5 条 Demo：正常 A 股、正常港股、市场不匹配、已退市、已在目标池；以已加载公共池/股票基础/股票调库 Demo、具备双权限、调入且关闭清空为前提，实际结果随配置数据变化。正式导入前删除 5 行。
  • 仅解析首表，支持 xls/xlsx、5MB、最多 2000 个非空数据行，保留真实行号；各列内容超过 200 字明确失败。
  • uploadExcel multipart 为 request JSON、file、originalFileNameListJson；重选合法文件先取消旧未提交批次，取消失败保留现场，非法文件不取消旧批次。

校验与提交

股票 Excel 使用服务器暂存数据和校验快照，只接受目标池已发布且含实际人工审批的一般流程。

POST /api/v1/stockPoolExcelImport/queryItemPage POST /api/v1/stockPoolExcelImport/queryTask POST /api/v1/stockPoolExcelImport/checkImport POST /api/v1/stockPoolExcelImport/submitImport POST /api/v1/stockPoolExcelImport/cancelImport

导入明细与调库校验

  • queryItemPage 按 impId、代码/名称关键字 keyword、校验结果 chkRslt 及分页查询原始行；queryTask 返回批次摘要与展开校验快照，刷新摘要保留当前分页和流程选择。
  • checkImport 重新解析股票/目标池，检查 excel_importable + adjustable 双权限；复用状态、市场、品种、行业、评级、容量、在途、来源、开放日、冻结期和限制池规则。
  • 主项失败阻断该来源整组，其附属项不可单独提交；失败关系保留原因，关闭关系仅提交主项，开启则提交通过的关系项。同股票同池跨来源冲突阻断全部相关组。
  • 清空差集为目标池当前有效成员减去全部可识别导入代码，包括失败但可识别行；跳过在途成员。先生成清空调出申请，再生成导入申请，不立即出池或预释放容量。
  • 重校验失败清除旧可提交快照；来源行以 sourceItemId 独立分组，避免同股票不同来源行混用结果。

提交、流程与权限

  • 选择流程弹窗显示服务端候选；仅目标池 normalInbound / normalOutbound，且已发布并含实际人工审批。快速、批量专用和全自动一般流程不可用。
  • 不提供报告材料入口，要求报告的主项明确失败；不能照搬债券 Excel 的 batch 推荐策略。
  • submitImport 以 impId 读取持久化来源、固定选项与 result_json，客户端只回传已有候选流程选择及本批原因意见，不信任其股票、池、方向等业务字段。
  • 允许提交部分通过来源组；服务端锁定批次，核对完整有效关系集合，再稳定顺序锁整批股票及目标池，所有复核通过后写日志、步骤；任一失败整批回滚。
  • 每来源独立 STOCK 批次；主项“Excel导入/Excel清空”，关系项沿用联动/互斥。提交为 00，必须进入人工审批，终审 20 才落池。
  • cancelImport 仅取消未提交批次；已提交防重，页面清空只重置界面。提交结果、日志 ID 与批次列表保存在服务端快照；管理员展示批次号。

关键规则与当前实现说明

与当前股票业务实现一致的状态、权限及数据边界。

  • 使用公共暂存表，以 biz_type=stock_pool_excel 隔离；不新增股票专属导入表，模板为资源文件，不在前端执行清库或初始化。
  • 清空仅生成调出审批申请，不能因生成清空项而提前释放容量；失败但能识别的导入股票仍从清空差集中排除。
  • 部分通过来源组可以提交，但同次提交是原子事务；失败来源组、孤立关系项及冲突来源组不能通过修改客户端快照绕过。
  • 上传取消、校验、提交共用批次锁及业务隔离；已提交批次不允许再次上传、提交或取消，失败时保留可检查现场。
  • Excel 导入/清空主项在终审和驳回修改重新提交时继续复核最新报告要求；即使未变更附件也不能绕过规则变化。评级与权限同样复核。
  • -1 无效 / 00 流程中 / 11 驳回待修改 / 20 审批通过 / 21 审批驳回 / 32 自动处理预留 / 99 发起人已撤回；仅 20 更新当前池状态。
