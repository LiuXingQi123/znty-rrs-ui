股票池 Excel 导入

股票研究 · 四列模板 → 导入明细 → 调库校验 → 选择一般流程 → 提交审批申请。

模板与页面参数

列名填写要求
父池名称 / 子池名称按直接父池及子池名称解析支持股票的启用叶子池；多匹配明确失败。
股票名称 / 股票代码代码使用文本格式，保留前导零及市场后缀；名称以主档为准，评级读取已有评级记录。

支持 xls/xlsx、5MB、首表最多2000个非空数据行。明细保留Excel真实行号，名称及代码可筛选分页。模板下载编码为 stock_pool_import，第二表附填写说明。

模板内置5条Demo示例：正常A股调入、正常港股调入、市场不匹配、已退市、已在目标池。第二表标注真实行号及预期结果；以已加载公共池、股票基础与股票调库Demo、具备目标池双权限、选择调入并关闭清空为前提，实际结果随当前配置及数据变化。正式导入前请删除这5行并填写实际数据。

默认调入、关闭清空、开启联动互斥。上传后固定方向、清空和关系选项；调整原因及意见可在提交前修改（各最多1000字）。更改固定选项须清空页面重新上传。

校验、清空与审批

  • 复用股票状态、市场、品种、行业、评级、容量、在途、来源池、开放日、冻结期及限制池规则，并检查调整与Excel导入双权限。
  • 仅允许目标池配置的已发布一般人工审批流程。快速、批量、自动一般流程不可用于导入；不提供报告材料入口，要求报告的主项明确失败。
  • 关闭联动互斥时只提交主项，开启时提交通过的关系项；失败主项阻断本组，失败关系保留原因。不同来源组同股票同池冲突时全部相关组失败。
  • 清空仅适用调入：目标池有效成员减去可识别导入名单，跳过在途成员；失败但可识别的导入行仍保留。先保存清空调出申请，再保存导入申请，不提前释放容量。
  • 允许提交部分通过来源组。客户端只选择服务端候选流程；提交复核最新规则及关系集合，任一复核或写入失败整批回滚。
  • 每个来源行独立STOCK批次，主项类型为Excel导入或Excel清空，关系项保留联动、互斥类型。提交状态为00，终审通过20才落池；终审及驳回修改继续复核报告和评级。

批次与接口

沿用证券及基金导入的上传取消顺序、失败现场保留、重校验及已提交批次防重。重选合法文件前先取消旧批次，取消失败保留原结果。已提交批次的清空仅重置页面。

全部POST，前缀 /api/v1/stockPoolExcelImport：uploadExcel、queryTask、queryItemPage、checkImport、submitImport、cancelImport。上传使用multipart的request JSON、file及originalFileNameListJson。
