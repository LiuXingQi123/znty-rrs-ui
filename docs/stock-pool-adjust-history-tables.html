股票池调整历史查询

股票研究 · 沪市、深市、港股 · 独立股票表组

查询与详情

条件：投资池、证券代码、调整日期范围、行业、调整人、调整方向、审核状态。行业为历史日志中的真实选项，覆盖林业、渔业等。表格：调整人、提交日期、证券名称、证券代码、行业、调整类型、调整方向、投资池、审核状态，以及债券同款分页序号。

查询全部未删除日志，名称、行业及评级保留提交时值；不以当前基础信息覆盖历史列。名称或代码打开股票详情，携带日志、批次、池，详情基础信息实时读取。手工、联动和互斥标签沿用统一颜色。

API

POST /api/v1/stockPoolAdjustHistory/queryStockPoolAdjustHistoryPage。参数 poolIds、stockCode、adjustTimeStart、adjustTimeEnd、industryCode、adjusterName、adjustMode、auditStatus、pageIndex、pageSize。queryIndustryList 返回 industryCode / industryName；exportStockPoolAdjustHistoryExcel 复用所有筛选条件，不传分页，返回标准 Base64 文件对象。

日期均为 yyyy-MM-dd，按自然日筛选；调整方向按债券传“调入/调出”，审核状态使用统一 -1 / 00 / 11 / 20 / 21 / 32 / 99 标签。

独立数据表

表职责

自选复用 my_security_pool；报告附件复用 sys_attachment，主表分类与业务域为 stock，和债券/基金日志 ID 隔离。SQL 位于后端 sql/stock/，表结构和 Demo 成对，支持独立脚本任务；前端页面不执行清库或初始化。
