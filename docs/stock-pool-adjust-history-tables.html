股票池调整历史查询

查询股票调入、调出及关系项的完整调整历史，按提交时名称、行业和评级留痕追溯，并支持条件导出及批次详情查看。

业务流程总览

从页面操作到数据库读写的主要路径。

1. 初始化条件加载股票池树及实际历史行业选项。
2. 历史分页按池、证券代码、日期、方向与审核状态查询。
3. 留痕展示名称、行业和评级使用日志提交时数据。
4. 详情追溯携带日志、批次及目标池进入股票详情。
5. 条件导出复用全部条件导出 9 个业务列。

历史分页查询

历史覆盖全部未删除日志，默认不限定审核状态；只读查询不改变股票当前池。

POST /api/v1/stockPoolAdjustHistory/queryStockPoolAdjustHistoryPage POST /api/v1/stockPoolAdjustHistory/queryIndustryList POST /api/v1/stockPoolAdjustHistory/exportStockPoolAdjustHistoryExcel POST /api/v1/common/queryPoolTreeList

主查询

  • 主表 ip_adjust_log_stock 仅固定过滤 is_deleted=0，不追加 audit_status=20 条件。
  • 按 submit_time DESC, adjust_batch_no DESC, id DESC 倒序分页；通过投资池关联及服务层映射回填 targetPoolPath。
  • 历史股票名称、行业、最新/上次评级来自日志留痕；不关联当前主档来覆盖这些历史值，也不创建行情全量快照。
  • 列表列为调整人、提交日期、证券名称、证券代码、行业、调整类型、调整方向、投资池、审核状态，另有债券同款分页序号。
  • 点击名称/代码打开股票详情，携带 stockCode / adjustLogId / adjustBatchNo / targetPoolId；历史行可用日志主键 id 定位。

筛选与派生

  • 条件为投资池、证券代码、调整日期范围、行业、调整人、调整方向、审核状态；参数 poolIds / stockCode / adjustTimeStart / adjustTimeEnd / industryCode / adjusterName / adjustMode / auditStatus。
  • 日期按 submit_time 自然日过滤，发送 yyyy-MM-dd，结束日转换为次日零点开区间；代码和调整人模糊匹配，行业、方向和状态精确匹配。
  • queryIndustryList 从全部未删除历史日志取实际非空行业 code/name，包括林业、渔业等；不从股票主档或当前页临时推导选项。
  • 池树传 includeVarietyCodes: ['stock']；调整方向传“调入/调出”，审核状态传统一 code，由前端字典和 Tag 展示。
  • exportStockPoolAdjustHistoryExcel 不传分页，复用全部筛选及排序；导出 9 列，返回 fileName / contentType / contentBase64。列表只接受最后一次请求响应。

涉及表、用途与触发场景

读写口径包含页面初始化、主业务接口及其正常后续流程；只读查询与提交后的审批落地区分说明。

表名用途读写触发场景
ip_adjust_log_stock未删除股票调整日志及提交时名称、行业、评级留痕。查询历史分页、实际行业选项、全部条件导出、定位股票批次。
ip_investment_pool当前有效投资池名称与全路径。查询池树初始化、列表关联及路径回填。
rrs_stockinfo / rrs_stock_rating股票实时基础信息及最近两次评级。查询进入详情后展示实时资料；历史分页本身不以当前资料覆盖日志。
ip_adjust_step_stock批次审批运行步骤与处理意见。查询从历史进入股票详情后展示完整流程记录。
ip_pool_status_stock当前有效股票池状态。查询详情“当前所在池”区域；不作为历史分页主表。
sys_attachment股票日志关联的报告及其他材料。查询进入详情后按 stock 业务域列出附件与下载。

关键规则与当前实现说明

与当前股票业务实现一致的状态、权限及数据边界。

  • -1 无效 / 00 流程中 / 11 驳回待修改 / 20 审批通过 / 21 审批驳回 / 32 自动处理预留 / 99 发起人已撤回；仅 20 更新当前池状态。
  • 历史默认展示全部审核状态；“当前池查询”仅展示通过记录。手工、手动批量、Excel 导入/清空、联动和互斥调整类型按统一字典与配色展示。
  • 历史提交时留痕与详情实时基础信息分开使用；详情展示 股票简称、股票代码、所属行业、市场、昨收、最高、最低、平均、换手率、交易总量(手)、交易市值(万)、总股本(百万)、总市值(百万)、流通A股(百万)、A股市值(百万)。基础信息实时读取 rrs_stockinfo；空值留白，零值正常显示。换手率原值 1.25 展示 1.25%，不再乘 100；交易市值为当日成交金额，币种跟随市场；港股交易量按来源的“手”展示。
  • 评级按 rating_date DESC, id DESC 取最近两次未删除记录；buy / overweight / neutral / underweight / sell 分别展示买入 / 增持 / 中性 / 减持 / 卖出，无评级留白。
  • 同批日志与步骤按 STOCK 批次追溯；详情附件以 businessDomain=stock 和股票日志主键隔离，不串用债券/基金同 ID。
  • 行业选项来自历史全量有效数据，导出复用筛选；Excel 为楷体 11 磅、浅蓝加粗表头、行高 20 磅、列宽 18，状态输出统一展示文案。
  • 股票表结构及 Demo 位于后端 sql/stock/；分管 rrs_stock_manager 只用于对应查询筛选，不改变历史数据；本页不执行清库或初始化。
