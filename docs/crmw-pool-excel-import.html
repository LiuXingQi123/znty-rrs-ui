CRMW池 Excel 导入

选择 CRMW 叶子池与方向后，按「CRMW代码 + 证券代码」模板上传组合名单，暂存批次，逐组合委托 CRMW 单笔校验，通过后再选择调库流程提交。提交后写 ip_adjust_log，仅 audit_status=20 落地 ip_pool_status_crmw。

业务流程总览

前端 pages/crmw_pool_excel_import.html：上方导入参数与上传，下方「导入明细 / 调库校验结果」双 Tab。API 前缀 /api/v1/crmwPoolExcelImport。

1. 导入参数选目标 CRMW 叶子池、调入/调出；选填原因与意见。
2. 下载并上传下载 CRMW 模板后拖入 xls/xlsx；解析 CRMW代码 / 证券代码写入临时表。
3. 导入明细分页查看凭证+标的主数据回填；可按校验状态筛选后点击校验。
4. 调库校验每行走 CRMW 单笔 checkCrmwAdjust；展示可调整项。
5. 选流程提交弹窗与批量 CRMW 一致；确认后写申请/步骤，仅 20 落池。

导入参数与上传

方向与原因作用于整批；目标池在页面选择启用叶子 CRMW 池，模板不含池名。

POST /api/v1/crmwPoolExcelImport/queryPoolList · /api/v1/commonFile/downloadTemplate · /api/v1/crmwPoolExcelImport/uploadExcel

导入参数

  • 目标池：启用叶子 pool_type=crmw，且当前用户具备 excel_importable（管理员 userId=1 放行）。仅一个池时页面自动选中。
  • 调整方向：in 调入 / out 调出。
  • 调整原因、调整意见均为选填，整批共享，写入临时主表 fld002 / fld003。
  • 无「导入类型」「首先清空目标池」「允许联动与互斥」；校验保留单笔完整展开项（手工 / 联动 / 互斥）。
  • 已生成批次（存在 impId）后参数锁定，需先清空再改目标池或方向。

模板与上传

  • 模板列：CRMW代码、证券代码。
  • 模板下载 templateCode：crmw_pool_import。
  • 上传 multipart：request JSON Blob + file + originalFileNameListJson（单元素原始文件名 JSON 数组），xls/xlsx，不超过 5MB。
  • 再次选择文件会覆盖当前未提交批次；上传后生成 impId，并按主数据回填全称 / 市场 / 类型。

校验与提交

先校验导入行主数据，再复用 CRMW 单笔调库校验；流程候选透传单笔，不注入 batch 流程（与 CRMW 批量一致）。

POST /api/v1/crmwPoolExcelImport/queryItemPage · checkImport · queryTask · submitImport · cancelImport

导入明细与调库校验

  • 明细分页 queryItemPage：可按 CRMW 代码或证券代码、校验结果（待校验 / 通过 / 失败）筛选。
  • 导入明细列：CRMW代码、CRMW全称、CRMW市场、证券代码、证券全称、证券类型、证券市场、校验、校验说明。
  • 每行调用 CrmwPoolAdjustService.checkCrmwAdjust（凭证 + 标的 + 目标池 + 方向）。
  • 保留 linkage / mutex / related 展开项；无清空目标池。
  • 校验结果列：CRMW代码、CRMW全称、CRMW市场、证券代码、证券全称、证券类型、证券市场、调整类型、调整方向、审批流程、调整说明、校验结果。
  • 校验结果调整类型：手工主项「Excel导入」；联动/互斥/关联与单笔一致。

提交、流程与权限

  • 提交弹出「选择调库流程」；交互形态对齐证券池 Excel 导入 / CRMW 批量。
  • 流程候选完全透传单笔 checkCrmwAdjust，不注入 batchIn/batchOut。
  • 按组合键 crmwScode|securityCode 分组调用 submitAdjustLog；整批共享附件上下文与批次号；存在直通项时先 recheckBeforeFinalApproval。
  • 仅 audit_status=20 落地 ip_pool_status_crmw；目标池须 excel_importable；管理员 userId=1 放行。
  • 导入批次号仅管理员可见；impId 仍用于后续校验 / 提交。

关键规则与当前实现说明

  • 目标池在页面选择：必须是启用叶子 CRMW 池，否则上传失败。
  • 模板仅 CRMW代码、证券代码；全称 / 市场 / 类型由 rrs_securityinfo 回填。
  • 调整类型：Excel 手工主项 Excel导入；联动/互斥/关联与单笔一致。
  • 每行复用 CRMW 单笔 checkCrmwAdjust / submitAdjustLog。流程候选透传单笔，不注入 batch 流程，见 CRMW池批量调整。
  • 仅 audit_status=20 落地 ip_pool_status_crmw；驳回 / 撤回只改日志与步骤。
  • 导入批次号仅管理员可见；目标池须具备 excel_importable，管理员放行。
  • 校验分层（check 全量 / submit 不重跑 / recheck 子集）与 CRMW 单笔一致，见 CRMW池调整。
