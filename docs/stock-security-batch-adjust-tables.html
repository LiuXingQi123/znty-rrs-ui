与证券池批量调整的差异

可选证券区域支持“主体编码”（issuerCode）和“证券全称”（securityFullName）查询，分别按证券主档 issuer_code、full_name 包含式模糊匹配；留空不限制，与其他条件按 AND 组合。输入框支持回车查询，查询回到第一页，重置时一并清空。表格展示“主体编码”（issuerCode）和“证券全称”（fullName），为空留白；原“发行人”或“发行主体全称”的查询条件和列表列统一显示为“主体全称”（issuer）。证券基础信息区保持原样。初始投资池列表保持原样，重新进入调入/调出时清空上述条件。

“是否特征”支持“是否标准信用债”（bondYesFlags 选项 stdCredit），勾选仅筛选证券主档 std_credit_flag=1，多选按 AND；不勾选不限制。对应表格追加 stdCreditFlag 列，沿用 isYesFlag 先转布尔值：1 显示“是”Tag，其他值（含 NULL）显示“否”Tag；接口与其他标识一样返回原始数值。只使用上游原始标志，不根据其他特征或 std_clause_flag 推断；CRMW 使用标的证券字段。

目标池与候选证券

  • 目标池：仅 pool_code=bond_product_root 子树下启用叶子（不含其它 bond_product 根如「债券产品库1」）。页头「请选择投资池」默认收起，树再限制 includeVarietyCodes: ['bond']。
  • 可选证券：调入展示来源池多选且必选；调出不展示也不传来源池，查询范围不是默认来源池的并集，而是不受来源池限制的全部候选证券。均支持主体编码、主体全称和证券全称模糊查询；代码/简称/市场/是否特征筛选同批量页，特征多选按 AND；候选表展示 ABS/担保/永续/次级/私募/含权/标准信用债七列是否类 Tag；内容滚动区为固定底栏预留空间，分页保持可见。

渠道标签

  • 手工项 adjustType 仍为 手动批量调整（无「存量专用」类型）。
  • 无 Excel 的 clearTarget / excel_importable 语义。
  • 与证券池批量、Excel 共用批量候选追加方法：完整单笔候选加配置的 batchIn/batchOut，统一推荐批量流程。

同构复用（与证券池批量一致）

同券跨市场按调库组整体校验：主券或任一关联券失败，整组不可调整，其他独立组不受影响。“放开规则”同步传递给所有关联券，仅跳过既有主体债入库矩阵，其余硬限制仍逐券执行。提交复用已有校验结果中的实际代码集合检查同池调入完整性，不再查询同券关系。

校验

  • 逐券转 AdjustCheckReq，调用 securityPoolAdjustService.checkAdjust。
  • 通用/类型规则、联动互斥、反阻断与单券一致（行业已注释；基金评分仅 check 且本页不传 fundRate）。
  • 流程候选保留完整单笔结果（白名单/信用债简易/产品库快速/默认/特殊/升降级等），追加配置的 batchIn/batchOut 并推荐批量；未配置时保留单笔推荐。提交透传所选流程，不用批量配置覆盖选择。
  • releaseRules=yes 仅跳过内评矩阵，其它硬规则仍执行。

提交与落池

  • 整批一个事务，任一失败全部回滚；防重复提交窗口与批量同构。
  • 按触发主券分组调用 submitAdjustLog；共享附件与 BatchNoContext。multipart 同时传递与 files 同序的 originalFileNameListJson，用于保留中文原始文件名。
  • 直通：isDirectAdjustFlow + recheckBeforeFinalApproval（动态子集，见证券池调库「校验分层」）。
  • 仅 audit_status=20 落地 ip_pool_status；驳回/撤回不改在池。
  • 后续审批复用证券池调库 Flow 服务。

  • 可选证券默认 10 条/页；担保人/权益人按四类关系主体查询并默认选中第一条，115202000 展示为“债务主体”。ABS 支持自选权益人，并联动担保人主体内评分；表格使用带搜索图标的可清空输入框，聚焦或点击图标打开选择弹窗，清空后解除自选。自选权益人弹窗采用带标签的主体编码/名称查询区；点击行或单选框选择主体，选中行高亮，最新内评以标签展示；底部显示已选主体全称和编码。确认前仅暂存选择，取消保留原值。主体编码、主体全称和内评列按弹窗可用宽度自适应分配。

快速入库与材料豁免

信用债简易资格在下一步沿用原方法计算；产品库快速资格独立判断，目标为 bond_product_root 子树启用叶子，当前有效来源为信用债一至三级、转债核心/重点或信用风险缓释工具库。本次待申请来源不计入当前在库。

满足快速资格即免除本次信评报告、报告引用及其他附件要求，与选择快速、一般、特殊或批量流程无关。同组联动、互斥和关联市场项跟随主项；关联码逐码判断，任一不符则整组无快速材料豁免。无资格主项和独立调出沿用原材料规则。

行级 materialExemptionType 为 creditBondSimple / productSource，无资格时为空；申请、详情调库、审核页下一步及三个批量入口统一按行级资格提示“本次免提交材料（信评报告及其他附件）”。切换流程不改变资格和提示，详情/审核补齐批量调入、批量调出标签。不显示合同范围确认提示，不增加勾选，现有材料入口及内容保留。

单笔推荐保留原规则；批量、存量和 Excel 追加配置的批量候选并统一推荐批量。材料豁免不改变所选流程 ID、Key、类型，人工审批继续办理。提交不重查信用债矩阵、入库经历或历史报告；产品来源复用已有在库集合。补充的报告引用仍验证并保存，原准入、落池复核及整批事务保持不变，不改表。
