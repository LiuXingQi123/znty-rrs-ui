存量证券批量调整

页面 pages/stock_security_batch_adjust.html · API /api/v1/stockSecurityBatchAdjust

与证券池批量调整差异

  • 目标池：仅 pool_code=bond_product_root 子树启用叶子（不含债券产品库1）。
  • 可选证券：来源池多选必选（CRMW / 信用债一~三级 / 转债核心·重点）；发行主体模糊查询；代码/简称/市场同批量。
  • CRMW 来源读 ip_pool_status_crmw；其它来源读 ip_pool_status。
  • 校验/提交与证券池批量同构：委托 SecurityPoolAdjustService.checkAdjust / submitAdjustLog，流程候选透传、不注入/不回填 batchIn·batchOut；直通走 isDirectAdjustFlow + recheckBeforeFinalApproval。
