业务流程总览

从页面操作到数据库读写的主要路径。

1. 初始化筛选加载投资池树、证券类型和页面状态选项。
2. 组合查询按池、证券、日期、调整人、发行人等条件分页。
3. 状态计算根据到期日计算存续或到期。
4. 路径回填将叶子池名称转换为完整投资池路径。
5. 收藏维护按用户新增或逻辑取消我的证券收藏。

证券池分页查询

只展示已经生效且未删除的证券池状态。

POST /api/v1/securityPoolQuery/querySecurityPoolPage · querySecurityTypeList · querySecurityStatusList

查询主线

  • 主表 ip_pool_status 固定过滤 audit_status='20'、is_deleted=0、security_type != 'crmw'（仅排除 CRMW 凭证；禁投/观察/黑名单中的债券仍可展示）。
  • 关联投资池：LEFT JOIN ... p.is_deleted=0。池被软删后，状态行仍可因 audit=20 出现，但池名/全路径常为空（路径映射也只含未删除池）。
  • 按 entry_time DESC, id DESC（id 为 ip_pool_status 主键）倒序分页，Service 回填池全路径。
  • 不做 VIEWABLE 权限过滤（列表 SQL 与池树均无 viewable 交集；与主体池/禁投池查询不同）。
  • 列表为空时单元格留白，不使用「-」占位；状态/类型等枚举用 el-tag 展示。

筛选条件

  • 支持多池树、证券代码/简称/类型、入池日期区间、调整人和发行人。
  • 存续/到期由 maturity_date 与当前日期比较（动态计算）。前端默认 securityStatus=active（存续）；清空状态下拉才查全部。到期日为空的券既不命中 active 也不命中 matured。
  • 「我的证券」通过当前用户有效 my_security_pool 记录过滤。
  • 投资池树：/api/v1/common/queryPoolTreeList，前端传 excludePoolTypes: ['crmw','forbidden']（树上选不到 forbidden；列表无池筛选时禁投池上的债仍可能出现）。类型选项来自本模块接口。

我的证券池收藏

收藏仅影响个人视图，不改变正式证券池状态。

POST /api/v1/securityPoolQuery/addSecurityToMyPool · deleteSecurityFromMyPool

新增收藏

  • userId 和 securityCode 建议前端必填（Service 直接调 mapper 无空值校验）。
  • 若已存在有效收藏则直接返回；否则新增 status='use' 记录。

取消与回显

  • 取消时按用户+证券代码更新收藏状态（逻辑取消，非物理删行）。
  • 列表分页结果回填 mySecurityPoolId（关联当前用户有效收藏），前端据此展示星标；另有 queryFavoritedCodeList 接口但当前页面未单独调用。
  • 取消收藏不会产生调出日志，也不会改 ip_pool_status。

涉及表、用途与触发场景

读写口径包含页面初始化、主业务接口及其正常后续流程。

表名 用途 读写 触发场景
ip_pool_status 已生效证券池状态，是列表主数据 查询 分页、证券类型选项
ip_investment_pool 目标池名称与完整层级路径 查询 列表关联、路径回填、池树筛选
rrs_securityinfo 发行人、全称、票息和日期等证券资料 查询 列表字段和存续状态判断
dict_security_type 证券类型名称 查询 列表展示和类型下拉
my_security_pool 当前用户证券收藏 查询 新增 更新 收藏、取消收藏、仅看我的证券

关键规则与当前实现说明

  • 正式池查询只认 ip_pool_status.audit_status='20' 且 is_deleted=0，并固定排除 CRMW 凭证（security_type != 'crmw'；CRMW 在独立页面查询）。对比：调整历史默认全 audit_status。
  • 本页无 VIEWABLE 过滤；池树 exclude crmw/forbidden。与主体/禁投查询（有 viewable）不同。
  • 证券状态不是独立表字段，由到期日动态计算；默认筛存续，空到期日边界见上。
  • 收藏表与正式证券池状态完全分离，取消收藏不会调出证券。
  • 前端状态下拉用本地字典；后端有 querySecurityStatusList，当前页面未调用该接口。
  • 本页只读查询 + 收藏维护。点证券名称/代码走 openSecurityAdjustDetail，工作台新开详情（resolveAdjustLogId(row, false) 用状态表 adjust_log_id，不是本行 id）；调库请走证券池调整/批量调整。
本页依据当前 Controller、Service、Mapper XML、需求文档和前端调用链整理；后续代码规则变化时应同步维护。
