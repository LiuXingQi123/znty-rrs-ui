股票池调整

股票研究 · 沪市、深市、港股 · 独立股票表组

操作路径

股票列表 → 代码/简称或调库按钮 → 股票基础信息与当前所在池 → 调入/调出双栏选池与报告材料 → 下一步校验 → 原因建议 → 选择流程 → 提交。页面与证券池调整保持同款布局、固定底栏、材料弹窗、分组标签、空状态和加载状态。股票不需要基金评分、投资类型或风管领导审批字段。

股票基础信息与口径

申请、审核和详情均展示 股票简称、股票代码、所属行业、市场、昨收、最高、最低、平均、换手率、交易总量(手)、交易市值(万)、总股本(百万)、总市值(百万)、流通A股(百万)、A股市值(百万)。基础信息实时读取 rrs_stockinfo；空值为空白，数值零正常显示。换手率 1.25 展示 1.25%，不再乘 100。交易市值表示当日成交金额，币种跟随股票市场；港股交易量直接显示来源的“手”。市场编码 SSE / SZSE / HKEX 由前端转换中文。

评级编码 buy / overweight / neutral / underweight / sell 对应买入 / 增持 / 中性 / 减持 / 卖出；按评级日期、主键倒序取最近两次有效记录，无评级不占位。

规则和流程

默认 normalInbound / normalOutbound 一般流程。目标池配置快速流程时提供 fastInbound / fastOutbound，缺失或无效配置明确失败。验证权限、市场、品种、上市状态、容量、在池状态、在途重复、来源池（多个来源按 OR）、行业、联动互斥、开放日、冻结期和报告。grade_astrict 空配置不限制；非空时最新评级必须在允许列表内，未评级和未知配置失败。分管仅用于查询，池权限决定调整资格。

整组日志和附件保存后推进主项，快速流程完成后整组复核并落池。一般流程仅状态 20 改变池状态，提交及终审重新校验；终审锁定池以控制并发容量。00 流程中、11 驳回待修改、20 通过、21 驳回、99 撤回；其余状态沿用统一状态机。

API

全部 POST /api/v1/stockPoolAdjust/，统一 ApiResponse；分页 data 为 PageResult。queryStockPage 传 stockCode、stockShortName、industryCode、marketCode、pageIndex、pageSize。queryIndustryList 返回 industryCode / industryName。queryStockDetail、queryStockPoolStatus 传 stockCode；queryAdjustPoolList 增加 currentUserId、adjustDirection（in/out）。checkAdjust 传 stockCode、currentUserId、items。

addAdjustLog 传 stockCode、adjustType、adjustReason、adjustAdvice、adjusterId、adjusterName、items；每项含 targetPoolId、adjustMode、itemTag、adjustGroupKey、flowId/flowKey/flowType。multipart addAdjustLogWithFiles 使用 request JSON Blob 和 files。附件索引 reportFileIndexes / materialFileIndexes，源附件 reportSourceAttachmentIds / materialSourceAttachmentIds。

报告与材料

每个池分别维护报告和其他材料；内部/外部报告支持标题、证券编码、报告类型、日期、分页、跨页勾选恢复、已选清单和下载。股票分类 stock_report_hand/in/out、stock_material_hand/in/out。审批完成后按债券方式沉淀报告。
