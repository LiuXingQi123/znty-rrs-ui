基金池查询

基金研究 · 当前生效池状态查询 · 条件筛选、分页与 Excel 导出

查询范围

主表为 ip_pool_status_fund，固定过滤 audit_status='20' 与未逻辑删除记录。关联 rrs_fundinfo 展示净值、规模及收益字段，关联 dict_security_type 取得基金类型名称，并由服务层回填投资池完整路径。

基金名称和基金代码可点击，样式及工作台页签跳转方式与证券池查询一致，进入对应基金池调库详情；不提供收藏操作。

筛选与接口

接口用途
POST /api/v1/common/queryPoolTreeList加载投资品种为 fund 的基金池树
POST /api/v1/fundPoolQuery/queryFundPoolPage按池、基金代码/名称、类型、入池时间和调整人分页查询
POST /api/v1/fundPoolQuery/queryFundTypeList加载当前基金池中出现的基金类型
POST /api/v1/fundPoolQuery/exportFundPoolExcel按当前全部筛选条件导出，不受当前页限制；使用同证券池查询格式的模板，表头带底色并使用楷体，首行及数据行行高均为 20 磅、列宽为 15 个字符

列表字段

基金名称、基金代码、投资池、调整人、入池时间、基金类型、基金经理、基金管理人、基金托管人、成立日期、发行期限（年）、最新净值、累计净值、日万份收益、7日年化收益率、最新规模、昨收盘、折/溢价。基金类型按接口返回的类型编码固定着色：封闭式基金红色、开放式基金灰蓝色、QDII 基金品牌蓝色、LOF 基金琥珀色、ETF 基金绿色；未知类型使用默认灰蓝色，类型名称变化不影响颜色。
