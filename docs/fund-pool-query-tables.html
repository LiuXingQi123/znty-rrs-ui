业务流程总览

查询审批通过的基金当前池状态，关联基金资料、投资池层级和品种字典，支持条件筛选、详情查看与 Excel 导出。

1. 加载查询选项加载基金池树及当前有效池状态中的基金品种。
2. 设置筛选条件选择投资池、基金、品种、入池时间和调整人。
3. 查询当前状态分页查询已生效且未删除的基金在池记录。
4. 查看基金详情点击基金名称或代码，携带日志、批次和目标池参数打开详情。
5. 导出筛选结果复用当前全部筛选条件导出 Excel，不受当前分页限制。

基金池分页查询

主查询以基金当前池状态为准；基金主档用于补充名称和基础资料。

POST /api/v1/fundPoolQuery/queryFundPoolPage · queryFundTypeList

查询主线

  • 主表 ip_pool_status_fund ips，固定筛选 ips.audit_status=20、ips.is_deleted=0。
  • 左连接未删除的 ip_investment_pool 与 rrs_fundinfo；内连接有效基金大类 dict_security_type。
  • 名称优先取基金主档，缺失时取池状态：COALESCE(fi.fund_name, ips.fund_name)；由服务补齐投资池完整路径。
  • 按 entry_time DESC, id DESC 排序；品种下拉从有效在池记录中去重，并按字典顺序展示。

筛选条件

  • poolIds：投资池多选；池树由 POST /api/v1/common/queryPoolTreeList 加载，限定 includeVarietyCodes=[fund]。
  • fundCode：基金代码模糊查询；fundName：基金全称或简称模糊查询；securityType：品种精确匹配。
  • entryTimeStart / entryTimeEnd：入池时间上下界；adjusterName：调整人模糊查询。
  • pageIndex / pageSize：分页参数；重置后按默认条件重新查询。

基金详情与 Excel 导出

查看在池基金的关联调库详情，或导出当前筛选下的全部有效记录。

POST /api/v1/fundPoolQuery/exportFundPoolExcel

详情入口与展示

  • 基金名称和代码均可打开 fund_pool_adjust_detail.html，携带 fundCode / adjustLogId / adjustBatchNo / targetPoolId。
  • 列表包括名称、代码、投资池、调整人、入池时间、品种，以及基金经理、管理人、托管人、成立日、发行期限等资料。
  • 净值资料包括单位净值、累计净值、万份收益、七日年化收益、规模、前收盘价及折溢价。

导出规则

  • 导出复用列表筛选；服务查询全部匹配记录，不导出当前页的局部数据。
  • 输出 .xlsx，18 列业务字段与列表口径一致；基金类型在前端按字典名称展示。
  • 模板沿用债券查询导出样式：楷体、20 磅行高、15 字符列宽及统一表头。

涉及表、用途与触发场景

按本模块实际执行阶段标注读写；表组内具体表的作用见用途与触发场景。

表名用途读写触发场景
ip_pool_status_fund当前审批通过、未删除的基金在池记录。查询分页查询、基金品种去重、全量条件导出。
rrs_fundinfo基金名称及经理、管理人、托管人、净值等基础资料。查询分页查询与导出时左连接主档，名称缺失时回退池状态快照。
ip_investment_pool池名称、层级路径和基金投资池树。查询加载基金池树，查询与导出时关联池名称、补齐完整路径。
dict_security_type有效基金品种及显示名称、排序。查询主查询限定基金大类；从当前有效池状态中生成品种下拉。

关键规则与当前实现说明

  • 本模块只读，不生成调整日志、不修改基金池状态，也不提供“我的证券池”收藏功能。
  • 当前池查询只展示审核通过的状态；全状态申请流水应进入 基金池调整历史。
  • 基金类型标签统一按字典展示：closed_fund 危险色、open_fund 信息色、qdii 主色、lof 警告色、etf 成功色；空值留空。
  • 基金审核与详情的加载及处理规则见 基金池调库审核与详情。
查询主线、筛选条件、表读写与导出规则均按实际基金实现说明；章节组织与债券“证券池查询”对应。
