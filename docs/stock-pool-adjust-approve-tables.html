股票池调库审核与详情

股票研究 · 沪市、深市、港股 · 独立股票表组

入口和状态机

我的事宜 businessDomain=stock、businessScene=stockAdjust 使用 stockCode 定位。待处理打开审核，已完成和我发起的打开详情；角色 2、3、7、8、9、10 及演示用户 1、5 有股票入口，处理权限沿用统一管理员/待办规则。本人待办优先，原演示管理员可代办其他人的步骤。

审核保留会签、驳回修改、重新提交和终止流程。只有状态 20 落池；通过时整组复核。驳回或终止需要处理意见和二次确认。状态 11 且当前步骤 approvalStrategy=initiator 时可修改原因建议；修改阶段当前处理人可增加、删除股票报告与材料，变更统一随提交落库。

股票基础信息与口径

申请、审核和详情均展示 股票简称、股票代码、所属行业、市场、昨收、最高、最低、平均、换手率、交易总量(手)、交易市值(万)、总股本(百万)、总市值(百万)、流通A股(百万)、A股市值(百万)。基础信息实时读取 rrs_stockinfo；空值为空白，数值零正常显示。换手率 1.25 展示 1.25%，不再乘 100。交易市值表示当日成交金额，币种跟随股票市场；港股交易量直接显示来源的“手”。市场编码 SSE / SZSE / HKEX 由前端转换中文。

评级编码 buy / overweight / neutral / underweight / sell 对应买入 / 增持 / 中性 / 减持 / 卖出；按评级日期、主键倒序取最近两次有效记录，无评级不占位。

API 与隔离

POST /api/v1/stockPoolAdjust/queryAdjustLogList 传 stockCode、adjustLogId、adjustBatchNo、targetPoolId；queryAdjustStepList 传 adjustLogId、adjustBatchNo。附件列表 POST /api/v1/attachments/queryAttachmentList 必传 businessDomain=stock 及日志 ID，下载仅传附件 id。

submitAdjustAudit 传 adjustLogId、adjustBatchNo、stepId、processAction（approve/reject）、processComment、handlerId、handlerName；修改时补充 adjustReason、adjustAdvice。submitAdjustAuditWithFiles 使用 request JSON Blob + files，attachmentChanges 按日志含 reportFileIndexes、materialFileIndexes、reportSourceAttachmentIds、materialSourceAttachmentIds、deleteAttachmentIds。股票附件不能串用基金或债券绑定。

详情按实时主档展示基础信息，保留申请时名称行业评级日志、当前所在池、调库记录、原因建议及步骤，支持附件下载和 PDF 导出；返回关闭当前详情页签并回到来源。
