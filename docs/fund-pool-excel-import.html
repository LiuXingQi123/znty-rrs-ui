基金池 Excel 导入

基金研究 · 七列模板导入 → 只读预览 → 基金调库校验 → 选择一般流程 → 提交申请。页面结构、上传交互、双 Tab 和流程弹窗沿用证券池 Excel 导入。

模板与参数

顺序列名填写方式
1 / 2父池名称 / 子池名称服务端根据父子池名称解析目标基金池；页面不手动选择目标池。
3 / 4基金名称 / 基金代码代码匹配基金主数据，名称用于名单核对；代码应按文本填写并保留前导零和市场后缀。
5基金评分每行必填合法数字，不增加业务评分范围限制；现有字段最多保存六位整数、四位小数，超出存储精度明确提示失败。
6基金投资类型每行必填内部编码：stock 股票型、equity_hybrid 偏股混合型、money_market 货币型、bond_hybrid 偏债混合型、other 其余类型。
7风管领导审批每行必填 0（否）或 1（是），0 为有效值。

方向和选项作用于整批；允许联动与互斥默认勾选。仅调入可勾选“首先清空目标池”，勾选后必填清空评分、清空投资类型、清空领导审批；这些统一值只用于目标池差集自动生成的清空出库项，Excel 行仍使用各自七列数据。

上传后锁定方向、联动选项、清空选项及清空三字段。修改参数需要清空后重新上传。原因、意见为整批选填字段，可在提交前修改。

评分、投资类型、审批列为数字单元格时读取实际数值；不会因 Excel 显示格式舍入而隐藏非法审批值或超精度评分。

上传、明细与校验

  • 模板下载使用 templateCode=fund_pool_import。支持 .xls/.xlsx，文件不超过 5 MB、首表最多 2000 个非空数据行；上传后暂存至通用导入表。
  • 再次选择文件先取消旧的未提交批次，再上传新文件；取消失败时保留旧批次。已提交批次需先清空页面才能再次上传。
  • 导入明细只读展示七列值、Excel物理行号、校验结果与说明，基金名称使用主档名称；提供基金代码查询、全部/待校验/通过/失败筛选及分页。投资类型和领导审批以中文标签显示，非法编码仍显示原值；数据错误需要修正 Excel 后重传。校验结果同样显示来源行号，自动清空项行号为空。
  • 基金校验复用独立基金单笔调库链路，包含基金品种与市场、权限、在池状态、容量、在途、池关系、冻结期及开放日等规则；目标池还需具备 Excel 导入权限。
  • 不提供报告选择或附件上传入口；需要报告的手工项和清空项校验失败，不绕过既有基金报告规则。
  • 同一基金导入不同池时，每行通过 sourceItemId 保持独立；某行主项失败时，其联动/互斥项不得单独提交，不影响其他通过行。
  • 重新校验清除旧结果及流程选择。允许部分通过项提交；全失败或没有可提交主项时禁用提交。

流程与提交

校验结果显示基金代码/简称、目标池全路径、方向、渠道调整类型、三项基金调库信息、失败原因与警告。通过的手工 manual 和清空 clear 项各自选择基金单笔的一般流程；不注入证券 Excel 的批量流程。联动、互斥项跟随来源主项。

提交先打开“选择调库流程”弹窗；每个主项仅可选择服务端快照已有且可选的候选。页面回传 selectedFlowId/selectedFlowKey/selectedFlowType，不允许修改基金、池或方向。清空出库先于导入提交，调整类型分别标记 Excel清空、Excel导入。

提交写入基金日志与步骤，调库批次号使用 FUND 前缀；仅最终审批通过 audit_status=20 后落基金池状态。成功反馈为“基金池调库申请已提交”及实际数量；提交后禁用上传、校验及重复提交。导入批次号仅管理员可见。

POST 接口用途及主要数据
/api/v1/commonFile/downloadTemplate按模板编码返回 Base64 模板文件。
/api/v1/fundPoolExcelImport/uploadExcelmultipart：request JSON、file Excel、originalFileNameListJson。参数为方向、清空/联动选项、清空三字段、原因/意见和操作人。

/api/v1/fundPoolExcelImport/submitImport提交批次、原因/意见、操作人及已选流程，返回状态、adjustBatchNoList 和 logIds。
/api/v1/fundPoolExcelImport/cancelImport按 impId 取消未提交暂存批次。
