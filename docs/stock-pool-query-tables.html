股票池查询

股票研究 · 沪市、深市、港股 · 独立股票表组

查询条件及表格

条件：投资池、入池日期范围、股票代码、调整人、我分管股票、我的自选股。表格：股票名称、股票代码、所属行业、最新评级、上次评级、投资池、调整人、入池时间、操作（添加到我的股票池/移除）。沿用债券分页序号。只读取审批通过、未删除的当前池状态；分管和自选同时勾选取交集，允许同股票多池行。

名称或代码打开独立股票详情页签，携带 adjustLogId、adjustBatchNo、targetPoolId；查询只认 adjustLogId，不能把状态主键 id 当日志主键。相同业务键复用页签，不同业务同 ID 保持隔离。

股票基础信息与口径

申请、审核和详情均展示 股票简称、股票代码、所属行业、市场、昨收、最高、最低、平均、换手率、交易总量(手)、交易市值(万)、总股本(百万)、总市值(百万)、流通A股(百万)、A股市值(百万)。基础信息实时读取 rrs_stockinfo；空值为空白，数值零正常显示。换手率 1.25 展示 1.25%，不再乘 100。交易市值表示当日成交金额，币种跟随股票市场；港股交易量直接显示来源的“手”。市场编码 SSE / SZSE / HKEX 由前端转换中文。

评级编码 buy / overweight / neutral / underweight / sell 对应买入 / 增持 / 中性 / 减持 / 卖出；按评级日期、主键倒序取最近两次有效记录，无评级不占位。

API 与自选

POST /api/v1/stockPoolQuery/queryStockPoolPage，参数 poolIds、stockCode、entryTimeStart、entryTimeEnd、adjusterName、myManagedStocks、myStocks、currentUserId、pageIndex、pageSize。日期发送 yyyy-MM-dd，后端按自然日闭区间筛选。exportStockPoolExcel 复用筛选，无分页限制，返回 fileName、contentType、contentBase64。

addStockToMyPool / deleteStockFromMyPool 传 stockCode、currentUserId。myStockPoolId 非空表示已自选；添加幂等，删除须用户确认，同代码多池行同步更新，勾选我的自选股时删除后重查。
