股票池查询

查询已生效股票池状态，关联股票资料、最近两次评级、池层级和当前用户自选状态，并支持维护“我的股票池”。

业务流程总览

从页面操作到数据库读写的主要路径。

1. 初始化筛选加载股票品种的投资池树，读取当前用户。
2. 组合查询按投资池、代码、日期、调整人及分管/自选分页。
3. 资料与评级关联股票主档和最近两次有效评级。
4. 路径回填补齐池全路径和本人自选状态。
5. 自选与详情维护个人自选，或新开对应股票详情页签。

股票池分页查询

只展示已经生效且未删除的股票池状态；导出复用全部筛选条件，不受当前分页限制。

POST /api/v1/stockPoolQuery/queryStockPoolPage POST /api/v1/stockPoolQuery/exportStockPoolExcel POST /api/v1/common/queryPoolTreeList

查询主线

  • 主表 ip_pool_status_stock 固定过滤 audit_status=20、is_deleted=0；内连未删除股票主档及 category_type=stock 品种字典。
  • 按 entry_time DESC, id DESC 排序；同股票在多个池的状态各保留一行。服务层使用 queryPoolFullNameMap 回填完整池路径。
  • 评级按 rating_date DESC, id DESC 取最近两次未删除记录；buy / overweight / neutral / underweight / sell 分别展示买入 / 增持 / 中性 / 减持 / 卖出，无评级留白。
  • 回填当前用户匹配代码、品种、市场且 status=use 的 myStockPoolId；分管和自选采用存在性过滤，不放大行数。
  • 列表字段：股票名称、股票代码、所属行业、最新评级、上次评级、投资池、调整人、入池时间、操作；分页序号沿用债券页面。

筛选条件

  • 条件为投资池、入池日期范围、股票代码、调整人、我分管股票、我的自选股；发送 poolIds / stockCode / entryTimeStart / entryTimeEnd / adjusterName / myManagedStocks / myStocks / currentUserId。
  • 日期发送 yyyy-MM-dd；下限包含当天零点，上限转换为次日零点的开区间，包含结束日的全部毫秒。用户 ID 必填。
  • 代码、调整人使用模糊匹配；分管/自选同时勾选时取交集，只读取当前用户有效记录。
  • 投资池树调用 /api/v1/common/queryPoolTreeList，传 includeVarietyCodes: ['stock']，默认收起并支持搜索。
  • 分页传 pageIndex / pageSize，返回 PageResult；快速翻页只接受最后一次请求响应，空单元格留白。
  • 导出调用 exportStockPoolExcel，复用相同 SQL 与全部条件、不传分页；输出 8 个业务列，不含序号和操作列，返回 fileName / contentType / contentBase64。

我的股票池收藏

收藏仅改变本人视图，不产生正式调库申请，也不改变当前股票池状态。

POST /api/v1/stockPoolQuery/addStockToMyPool POST /api/v1/stockPoolQuery/deleteStockFromMyPool POST /api/v1/stockPoolQuery/queryFavoritedCodeList

新增收藏

  • addStockToMyPool 传 stockCode / currentUserId；服务端锁定真实股票主档，核实股票品种和市场。
  • 存在有效收藏时幂等返回；相同代码已有其他品种或市场记录时明确报错。新增 my_security_pool.status=use，主档锁防止并发重复插入。
  • 页面按股票代码控制请求加载状态，并同步更新同代码的多池行。

取消与回显

  • 移除前二次确认；deleteStockFromMyPool 仅将本人、该代码、匹配品种及市场的有效记录更新为 status=del。重复移除保持幂等。
  • myStockPoolId 非空表示已自选；移除后清空同代码行的自选状态，若勾选“我的自选股”则重新查询。
  • queryFavoritedCodeList 可查本人有效股票收藏代码；当前列表通过分页返回的 myStockPoolId 回显。其他用户记录不受影响。

涉及表、用途与触发场景

读写口径包含页面初始化、主业务接口及其正常后续流程；只读查询与提交后的审批落地区分说明。

表名用途读写触发场景
rrs_stockinfo / dict_security_type未删除股票主档、行业、市场与股票品种字典。查询列表关联、股票品种确认、自选维护前核实并锁定主档。
rrs_stock_rating最近两次未删除的股票研究评级。查询分页、全部条件导出中的最新评级和上次评级。
ip_pool_status_stock当前已审批通过的股票池成员，是列表主数据。查询分页与全部筛选结果导出；每股票每池保留一行。
ip_investment_pool目标池名称与完整层级路径。查询股票池树初始化、列表关联、服务层回填全路径。
rrs_stock_manager当前用户的有效股票分管关系。查询勾选“我分管股票”时通过 EXISTS 过滤，避免多人分管放大分页。
my_security_pool按用户、股票代码、真实品种及市场隔离的个人自选。查询 新增 更新自选筛选、myStockPoolId 回显、幂等添加与逻辑移除。

关键规则与当前实现说明

与当前股票业务实现一致的状态、权限及数据边界。

  • 本页查询有效成员，历史页查询全部未删除调整日志；两者主表与审核状态范围不同。分管关系只用于查询，不能替代投资池调整权限。
  • 名称/代码点击 openStockAdjustDetail，携带 stockCode / adjustLogId / adjustBatchNo / targetPoolId；查询页只认来源日志 adjustLogId，不能把池状态主键 id 当日志 ID。
  • 工作台按股票业务及代码、日志/批次、池复用详情页签；不同业务同 ID 保持隔离，返回关闭当前详情页签并回到来源。
  • 详情的 15 项实时基础信息为：股票简称、股票代码、所属行业、市场、昨收、最高、最低、平均、换手率、交易总量(手)、交易市值(万)、总股本(百万)、总市值(百万)、流通A股(百万)、A股市值(百万)。基础信息实时读取 rrs_stockinfo；空值留白，零值正常显示。换手率原值 1.25 展示 1.25%，不再乘 100；交易市值为当日成交金额，币种跟随市场；港股交易量按来源的“手”展示。
  • 市场 SSE / SZSE / HKEX 与评级由前端字典和标签展示；数值零不视为空值。
  • 导出使用股票查询模板：楷体 11 磅、浅蓝加粗表头、行高 20 磅、列宽 18；代码保留文本格式。
