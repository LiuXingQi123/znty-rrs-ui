流程入口分级规则提醒（并入事宜）

研究管理无独立菜单。定时 bond_grade_inconformity_alert 写待办；处理在「我的事宜」第三页签；旧页仅重定向。

并入事宜投资池维护

池树/关系/权限；锁池与冻结期可维护；开放日/行业/基金评分未开放；删除无引用检查。

基础配置投资池开放日维护

区间表；依赖隐藏 open_day_adjust；终审不重跑开放日。

开放日流程定义

版本画布；AUTO_PROCESS 已通；条件路由预留；停用/删除无在途检查。

流程配置规则管理中心

QLExpress 试跑；池上自动调入/调出绑定的是定时任务，不执行规则脚本。

规则引擎主体内评分档规则

期限×评分→准入池；parent_id=1 硬编码；全量硬删再插。

准入矩阵定时任务管理

sys_scheduled_task；不同 taskCode 无编排，依赖靠 cron 先后。
