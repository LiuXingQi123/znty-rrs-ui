股票池批量调整

股票研究 · 投资池列表 → 选择调入/调出 → 跨页勾选股票与共享材料 → 逐股票校验 → 确认一般流程 → 提交申请。两步工作台以基金池批量调整为模板，沿用证券批量的布局和交互，审批继续股票独立链路。

投资池与候选股票

  • 工作台及业务文档中的“股票池批量调整”均位于“股票池调整”之后。
  • 只展示当前用户有调整权限、启用且支持 stock 品种的叶子池，包含全路径、描述、市场、品种、上限及有效在池股票数量；管理员口径沿用股票单笔。
  • 调入排除目标池有效成员，调出只含目标池有效成员；以 ip_pool_status_stock.audit_status='20' 且未删除为准，数量按股票代码去重。
  • 候选按股票代码、简称、行业、市场筛选，沿用单笔股票状态、品种和市场约束。列表显示股票代码、简称、行业、市场、最新评级、上次评级、昨收及数据日期。
  • 评级 buy/overweight/neutral/underweight/sell 分别展示买入/增持/中性/减持/卖出，市场和评级使用既有标签。空值留白，零值正常显示。
  • 股票按代码跨页保留勾选，支持移除和清空；固定底栏为分页及末尾内容预留空间。

校验、一般流程与整批提交

  • 逐股票调用 StockPoolAdjustService.checkAdjust，复用权限、评级、品种、市场、状态、容量、当前池、在途、来源、行业、联动互斥、开放日和冻结期规则。
  • 每只股票一条手工主项及完整关系项，组键为 <stockCode>_stock-group-1。组内任一项校验失败则整组不可提交，其余通过的完整组可以提交；反向互斥项必须保留。
  • 仅提供目标池配置的 normalInbound/normalOutbound 一般流程。主项选择流程，关系项共用主项流程；错误 ID/Key/类型或不可用发布配置明确拒绝。
  • 统一填写原因和建议，页面各最多 500 字。返回第一步保留股票和材料；重新校验刷新结果，退出后忽略迟到响应。提交中禁止重复点击，成功返回池列表并刷新。
  • 提交一次锁定整批股票主档，再按池 ID 顺序锁定所有目标池；全部分组复核通过后保存日志、附件和步骤。任一最新复核或保存失败，整批事务回滚。
  • 手工主项标记“手动批量调整”，关系项仍为联动/互斥类型。每只股票独立 STOCK 批次，同股票主项与关系项共享该批次。
  • 待办、审核、驳回修改、撤回及详情继续股票既有链路；仅审批通过 20 时更新有效池状态，终审仍复核报告、评级、权限及并发容量。

股票报告与共享材料

材料区保留内部/外部报告双页签、标题、证券编码、类型及日期筛选、分页、跨页勾选、下载和已选汇总。本地股票报告和其他材料整批共享，报告库研究报告必须为股票品种且 securityCode 匹配已选股票，按股票归属分配到该股票完整分组。不匹配报告明确提示，不给其他股票使用。

同股票主项、联动和互斥项复用该组材料。后端按集合复核同股票报告来源及整批本地文件、其他材料一致，不一致请求在写入前拒绝。共享上传只保存一份物理文件，再按各条股票日志分别绑定；中文原文件名数组与上传顺序和数量一致。分类使用 stock_report_hand/in/out、stock_material_hand/in/out，关联表为 ip_adjust_log_stock。

各池 none/any/internal 报告要求、股票归属和来源有效性继续按股票单笔规则复核，终审再次验证。研究报告和其他材料仍按用途分别处理。

接口契约

全部 POST，统一 ApiResponse，分页 data 为 PageResult。

接口主要数据
/api/v1/batchStockPoolAdjust/queryPoolPagecurrentUserId/poolIds/pageIndex/pageSize，返回可调整股票叶子池及有效数量。
/api/v1/batchStockPoolAdjust/queryStockPagecurrentUserId/poolId/direction/stockCode/stockShortName/industryCode/marketCode/pageIndex/pageSize，返回方向过滤的候选股票。
/api/v1/batchStockPoolAdjust/checkAdjustcurrentUserId/poolId/direction/stocks:[{stockCode}]，返回单笔股票结构的完整 items、stockCount 及一般流程候选。
/api/v1/batchStockPoolAdjust/addAdjustLogJSON：用户、池、方向、原因建议及完整已选流程明细。返回 stockCount/submitCount/logIds/adjustBatchNos。
/api/v1/batchStockPoolAdjust/addAdjustLogWithFilesmultipart：request JSON、files、originalFileNameListJson，返回同上。

根参数 direction 为 in/out，明细 adjustMode 为单笔的 调入/调出。明细增加 stockCode，保留 targetPoolId/itemTag/adjustGroupKey/flowId/flowKey/flowType 及 reportFileIndexes/materialFileIndexes/reportSourceAttachmentIds/materialSourceAttachmentIds。股票数不重复计算关系项，日志数包含全部关系项；调整人与当前用户须一致。
