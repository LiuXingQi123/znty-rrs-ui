业务流程总览

按基金名称、代码和市场查询基金，跨页勾选后按日期区间导出逐日单位净值，每只基金独立一个工作表。

1. 查询基金按名称、代码、市场筛选有效基金主档。
2. 跨页勾选累计选择需要导出净值的基金。
3. 选择日期填写净值起止日期，包含区间两端。
4. 校验数据重读所选主档，校验日期与每日净值唯一性。
5. 生成 Excel每只基金独立 Sheet，按日期升序输出单位净值。

基金分页查询

选择导出对象时查询基金基础信息，不以基金当前是否在池为条件。

POST /api/v1/fundNavExport/queryFundNavFundPage

查询主线

  • 主表 rrs_fundinfo，只读取未删除记录。
  • 列表展示基金名称、基金代码和市场；按 fund_name, fund_code, id 升序排列。
  • 支持跨页勾选；发起新查询或重置条件时清空已有勾选，避免混用不同筛选结果。

筛选条件

  • fundName：基金全称或简称模糊匹配。
  • fundCode：基金代码模糊匹配；marketCodes：市场多选。
  • pageIndex / pageSize 控制基金列表分页；日期范围在导出弹窗填写，不参与基金列表筛选。

净值区间查询与 Excel 导出

服务以勾选代码和日期区间重新读取数据，每个基金独立输出。

POST /api/v1/fundNavExport/exportFundNavExcel

校验与净值查询

  • fundCodes 必须非空；服务去除空白代码并去重，然后校验所选基金仍有效且主档唯一。
  • navDateStart / navDateEnd 必填，格式 yyyy-MM-dd，开始日期不得晚于结束日期。
  • 查询 rrs_fund_nav，关联有效基金主档；只读取未删除净值，交易日期包含起止两端。
  • 按 fund_code, trade_date, id 升序；同一基金同一日期存在多条记录时明确报错，不静默覆盖。

工作簿与数据格式

  • 生成 基金净值_时间戳.xlsx；每只基金一个 Sheet，默认使用基金名称，并处理非法字符、超长和重名。
  • 固定两列表头“日期 / 基金净值”；日期为 yyyyMMdd 文本，净值取 unit_nav，使用数值单元格并显示六位小数。
  • 表头加粗，日期列宽14、净值列宽16；所选基金在日期区间内无净值时仍保留只有表头的工作表。
  • 下载文件由服务返回文件名、内容类型、大小和 Base64 内容，前端按文件响应下载。

涉及表、用途与触发场景

按本模块实际执行阶段标注读写；表组内具体表的作用见用途与触发场景。

表名用途读写触发场景
rrs_fundinfo导出候选基金与所选基金有效性、名称、市场。查询基金分页查询、导出前重读所选基金及构造工作表名称。
rrs_fund_nav基金逐日单位净值与交易日期。查询按所选基金和日期区间查询、检查同日重复并输出净值。

关键规则与当前实现说明

  • 本模块只读基金主档和净值表，不读取或改动基金调库日志、流程步骤和当前池状态。
  • 导出对象以勾选基金为准，导出期间以净值日期区间为准；基金列表的分页不截断净值记录。
  • 空净值保持空单元格；无数据基金保留工作表，便于区分“所选基金无区间数据”和“未选择”。
净值导出采用与债券文档一致的“查询主线 / 筛选条件 / 处理逻辑 / 表与场景 / 关键规则”组织方式，内容对应基金专有功能。
