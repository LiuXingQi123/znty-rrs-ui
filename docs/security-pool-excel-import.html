证券池 Excel 导入

页面：pages/security_pool_excel_import.html · API：/api/v1/securityPoolExcelImport

功能说明

  1. 选择导入类型（证券 / 主体）、调入/调出方向、选项与调整原因。页面不选择目标池，池由 Excel 父池/子池名称解析。
  2. 分别下载证券模板或主体模板后拖拽上传：
    • 证券模板列：父池名称、子池名称、证券名称、证券代码
    • 主体模板列：父池名称、子池名称、主体名称、主体代码
  3. 上传后在「导入明细」查看行数据；点击校验后切换到「调库校验结果」。
  4. 提交弹出「选择调库流程」对话框（与证券池批量调整一致），确认后写 ip_adjust_log。

导入类型差异

类型校验联动/互斥提交
证券 每行调用 SecurityPoolAdjustService.checkAdjust（与批量内部路径相同） 勾选后保留联动/互斥/关联码展开；不勾选仅手工项 按主券分组 addAdjustLog，并注入批量流程候选
首先清空目标池（仅调入）：对每个本批目标池，将「在池但不在本批名单」的成员按批量出库校验/提交（独立方法）； 本批编码若存在在途流程则该导入行失败；非本批编码的在途不纳入清空。提交顺序：先清空出库，再导入。
主体 每行调用 ForbiddenPoolAdjustService.checkCompanyAdjust 同样受「允许联动与互斥」过滤 按主体分组 addCompanyAdjustLog

临时表

表说明
sys_imp_tmp_batch导入批次主表；biz_type=security_pool_excel / company_pool_excel
sys_imp_tmp明细：fld001=代码，fld002=名称，fld003=父池，fld004=子池

主要接口

路径说明
POST /api/v1/commonFile/downloadTemplatetemplateCode：security_pool_import / company_pool_import
POST .../uploadExcelmultipart：FormData + apiPost（request JSON Blob + file，对齐调库）
POST .../checkImport内联校验 + 调库校验结果
POST .../submitImport内联提交（可选 checkItems 带流程选择）
POST .../queryItemPage明细分页
POST .../queryTask查询导入批次主表（含校验结果快照 checkItems）；前端刷新明细/校验结果时调用
POST .../cancelImport取消批次

权限

目标池须配置 excel_importable 权限；管理员 userId=1 放行。

上传后生成的导入批次号（impId，形如 IMP202608071347400001）仅管理员（userId=1）可见，非管理员该芯片不展示；impId 数据仍用于校验/提交等后续操作。
