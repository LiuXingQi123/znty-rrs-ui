恒生格式手动导出

按投资池和时间范围生成恒生格式 Excel，并由浏览器直接下载。

页面位置与操作

  1. 进入“债券研究 → 恒生格式手动导出”。
  2. 选择投资池；不选择时处理全部叶子投资池。
  3. 填写开始时间，可选填结束时间，并选择增量或全量模式。
  4. 点击“导出 Excel”，生成完成后浏览器自动下载文件。
投资池选择沿用“投资池维护 → 关系配置”的交互：左侧按树定位并点击叶子池，右侧展示已选投资池并支持逐项移除或清空；父级池仅用于展开和定位。

查询条件

条件是否必填作用
投资池否可选择一个或多个叶子池；未选择表示全部叶子池。
开始时间是增量模式的时间窗口下界，精确到秒；全量模式保留该统一必填项，但不用于过滤当前在库数据。
结束时间否增量模式的时间窗口上界；未填写时使用服务器当前时间。
导出模式是默认选择增量；全量导出当前在库数据，增量导出时间窗口 (开始时间, 结束时间] 内的有效调入、调出事件。
结束时间不能早于开始时间。手动导出不改变定时任务水位，也不更新业务调库日志的导出标记。

页面按“说明项：具体含义”的单列形式，固定展示增量模式、全量模式、投资池范围、文件结构和执行影响，不随当前导出模式切换而隐藏。

Excel 结果

  • 每个符合条件的叶子池按恒生池名称生成 Sheet；空池也保留 Sheet。
  • 表头固定为：证券名称、证券代码、操作类型、市场名称、备注。
  • 文件由接口返回并直接下载，不写入定时任务服务器目录，也不生成备份文件。
  • 文件名使用英文前缀和导出结束时间，例如 hs_pool_full_20260831_103000.xlsx。
